## Notepad++ Tips And Tricks

### Keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| `Alt` + mouse drag | Column (block) selection |
| `Alt+Shift+Arrow keys` | Column selection with the keyboard |
| `Ctrl+D` | Duplicate the current line |
| `Ctrl+Shift+Up` / `Ctrl+Shift+Down` | Move the current line up / down |
| `Ctrl+J` | Join the selected lines |
| `Ctrl+F` | Find / Replace (set *Search Mode* to *Regular expression* for regex) |

### Remove duplicate lines

**Edit > Line Operations > Remove Duplicate Lines** (or sort first with **Sort Lines Lexicographically Ascending**).

### Useful plugins

Install via **Plugins > Plugins Admin**:

* **Compare** — side-by-side diff of two open files
* **JSTool** — format (pretty-print) and minify JSON / JavaScript
